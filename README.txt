طريقة الاستخدام:
1) فك ضغط الملف أولاً (Extract All) - لا تفتح الصفحات من داخل الملف المضغوط.
2) افتح index.html في متصفح (Chrome / Edge / Safari).
كل صفحة مستقلة بالكامل ولا تحتاج إلى أي ملفات أخرى أو اتصال بالإنترنت.

How to use: extract the zip first, then open index.html in a web browser.
